Mount function

          

            The JavaScript entry is a function body. Query within
            ctx.root; return cleanup or register it with
            ctx.onCleanup(fn).
          

          
const button = ctx.root.querySelector('[data-notify]');
function notify() {
  ctx.notifications.publish({
    id: 'test', title: 'Hello', priority: 'high'
  });
}
button.addEventListener('click', notify);
return () => button.removeEventListener('click', notify);

          
Host API

          

            ctx.storage.get(key, fallback) /
            set(key, value) save panel-scoped preview state.
            ctx.layout.emit(name) emits declared expansion events.
            ctx.host.notifications offers publish, dismiss, list,
            and subscribe. ctx.notifications owns and cleans up
            panel-bound items.
          

          
Preview contract

          

            Sizes are columns × rows. Cell dimensions are CSS
            pixels, with a 14px gap. Each preview is the selected panel spanning
            those grid units. Bright, dark and minimal use actual dashboard CSS
            and tokens. Pinned panels reject new expansion requests.
            Disable/remount tests lifecycle cleanup.
          

          

            The sandbox uses the dashboard runtime, expansion controller,
            attention selection, and fit helpers. Studio notification
            presentation is a test harness. The Data API tab supplies Android,
            calendar and custom fetch response fixtures. Native services,
            account connections, built-in clock/weather/Dot adapters, gestures,
            full screen and Android permissions require dashboard/device
            testing.
          

          
Assets and scope

          

            Declare assets in the manifest and use
            asset:assets/icon.svg in HTML/CSS. Prefix CSS with your
            panel ID. Panels should adapt to their container and avoid internal
            scrolling.
          

          
Isolation

          

            Preview scripts run in an opaque-origin sandbox without workspace
            DOM or browser credentials. Network is blocked unless you enable
            declared HTTPS origins. This is a development aid; only install
            trusted code in the real dashboard.
